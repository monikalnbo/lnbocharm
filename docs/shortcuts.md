# 快捷键与按键映射表

三层映射：**渲染层（Monaco 命令）→ 窗口层（keydown）→ 系统层（Electron 菜单加速器）**。
终端内按键直接透传 PTY，不会被任何快捷键劫持。

## 编辑器（Monaco 聚焦时）

| 按键 | 动作 | 层 |
|---|---|---|
| `Ctrl/Cmd + S` | 保存当前文件并重新 Lint | 渲染层命令 |
| `F9` | 切换光标行断点 | 渲染层命令 |
| `F5` / `Ctrl+Enter` | 运行当前文件（自动保存） | 渲染层 → cf-run 事件 |
| `Ctrl+F` / `Ctrl+H` | 查找 / 替换 | Monaco 内置 |
| `Alt+点击图标栏` | — | （断点为左键单击图标栏）|

## 全局（窗口层）

| 按键 | 动作 | 说明 |
|---|---|---|
| `F5` | 运行当前文件 | 终端聚焦时不劫持 |
| `Esc` | 关闭设置面板 | 设置面板打开时 |

## 系统（Electron 菜单加速器，桌面端）

| 按键 | 动作 | 说明 |
|---|---|---|
| `Ctrl/Cmd + O` | 打开工作区文件夹 | 菜单加速器 |
| `Ctrl/Cmd + ,` | 打开设置 | 菜单加速器 |
| `Alt` | 显示/隐藏菜单栏（Win/Linux） | 菜单栏默认自动隐藏 |

> 注意：终端面板内所有按键（含 F5、Ctrl+C）都作为输入发送给 PTY，
> 这是正确行为——终端里的程序需要原始键盘输入。
